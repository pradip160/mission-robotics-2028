## Goal 
Today my goal was to learn how a robot can store and manage multiple restaurant delivery orders.

## What i learned 
- A dictionary can store one robot order ticket
- A list can store many order tickets like a robot mission queue. 
- A function helps keep the code clean and resuable 
- The robot can update and order status form pending to delivery or packing.
- The robot can count how many orders are pending, delivered or packing.

## Why this matters in robotics
In a real restaurant delivery robot, the robot need to remember many tasks. Each task has table number, food item, distance, priority, and status. This is similar to a mission queue in robot software.
